# Jornada na Palavra

App de leitura bíblica em caravana.

- `index.html` — o app (publicado pelo GitHub Pages)
- `biblia/` — textos bíblicos livres lidos dentro do app (veja `biblia/LEIA-ME.md`)
- `supabase/` — scripts do banco (diagnóstico, backup, correções, desfazer)
- `testes/` — testes automáticos (veja `testes/LEIA-ME.md`)
